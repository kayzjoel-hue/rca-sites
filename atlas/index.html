Chapter 02 / Travel

Make the journey fit the person.

Travel planning should begin with dates, group size, interests, accessibility needs and a realistic budget. A draft itinerary is not a booking confirmation; confirm availability and supplier terms directly before making commitments.

Chapter 06 / Working together

One source for each kind of truth.

Notion owns business doctrine, catalogue records and operating decisions. GitHub owns versioned website code and change history. The deployed website is proof only after the runtime is tested. A scheduled sync is not real until a workflow, credentials, schedule and end-to-end result are verified.

This route uses static content. No Notion API, CRM, geocoding, scheduled sync or AI backend is connected by this page.
